# AI Alignment Research Journal

## Overview

This repository documents my transition from Software Engineering into technical AI alignment research.

My goal is to systematically study modern AI systems, understand alignment challenges, reproduce selected experiments, analyze current research, and build the technical skills required for independent AI safety research.

This repository serves as my public research journal throughout that journey.

---

## Research Objectives

- Build a strong foundation in machine learning and large language models.
- Study AI alignment from first principles.
- Analyze research papers and technical reports.
- Design and document small reproducible experiments.
- Develop research thinking through structured notes and critical analysis.
